· 켜면 모의거래 포지션 모드가 헤지로 바뀌고(포지션·대기 주문이 없을 때만), 숏 신호(양봉 마감)에도 롱과 똑같은 방식으로 따로 진입해요. 롱 포지션과 숏 포지션이 서로 영향 없이 각자 1~6차까지 쌓이고 각자 익절돼요. 숏은 지정가 = 신호 양봉 종가 + 틱, 추가진입은 종가가 평단보다 gap% 이상 위, 익절은 평단 −%. 주문 금액·배수·레버리지·신호 선택은 롱과 같은 값을 써요. 끄면 롱만 진입해요.
익절 · 지정가 (포지션 줄이기 전용)
1차 수량: 1차 진입가 + %
2차+ 수량: 실제 평단 + %
· 1차가 체결되면 1차 수량을, 2차 이상이 체결될 때마다 (총 수량 − 1차 수량)을 새 평단 기준으로 다시 걸어요 (이전 2차+ 익절 주문은 취소 후 교체). 0을 넣으면 꺼요.
· 지정가 = 신호 음봉의 종가에서 입력한 틱 수만큼 아래예요. 그 가격이 이미 현재가보다 위면 현재가보다 한 호가 아래로 걸어요. 대기 주문(메이커)이라 가격이 내려오지 않으면 체결되지 않고 그대로 남아요 (자동 취소 없음 → ‘현재 주문’ 탭에서 취소).
· 추가진입 조건을 0으로 두면 평단과 상관없이 신호마다 추가해요. 6차까지 들어가면 포지션이 정리될 때까지 더 사지 않아요.
· 주문 금액은 포지션 크기(명목 금액)예요. 예) 1차 300, 배수 2 → 300 / 300 / 600 / 1200 / 2400 / 4800. 레버리지를 비우면 주문 패널의 값을 써요.
· 켤 때 보고 있던 종목·분봉으로 고정돼요. 차트를 다른 종목으로 바꿔도 백그라운드에서 계속 작동해요 (자동매매 전용으로 캔들·청산을 따로 받아요. 이때 캔들은 바이낸스 기준이고, 이 페이지는 열어둬야 해요).
· 켠 이후에 마감된 봉의 신호만 따라가요. 실거래를 연결하면 멈춰요.
